# Pathrule Homebrew tap

```sh
brew install pathrule/tap/pathrule
```

The formula installs the Pathrule CLI 1.0.6 from its signed per-platform tarballs on
releases.pathrule.io (macOS and Linux, arm64 and x64). It runs on Homebrew's `node@24`.
